# Learnings

One file per durable learning: `YYYY-MM-DD-<slug>.md`, linking the test IDs that support it and its
confidence. The registry (`adlab learning list`) is the source of truth; these files make learnings
reviewable in pull requests. Old or contradicted learnings get flagged, not deleted.

```md
# Problem-framed hooks beat time-saving claims (busy parents, 9:16)

- Confidence: low (one test)
- Evidence: tst_…
- Tags: hookType=problem, persona=busy-parent, format=motion_graphic
- Reviewed: YYYY-MM-DD
```
